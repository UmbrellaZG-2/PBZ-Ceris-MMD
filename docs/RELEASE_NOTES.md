# 版本说明

## v42.0 运行库（2026-11-14）

- 修复**前额两侧的长发会插进身体（陷进胸口/乳房皮肤 2–5 cm）**：量下来这不是偶发，v41 的每一帧都有约 124 个发顶点在皮肤内、最深 0.6 单位。
- 根因两条：① 躯干上 5 只胶囊是照内衣体积做的，表面在真实皮肤里约 0.9 单位，发束要沉这么深 Bullet 才会反应；② 发束自己的碰撞盒与该骨驱动的网格质心错位（中位 0.171、最大 0.551 单位）且比网格窄，所以光推骨永远够不到被穿的那片布。
- 修法（只改 Bullet 形状，**PMX 资产零改动**）：躯干胶囊按 2.0 倍半径重建到皮肤表面、broadphase mask 收窄成只和 group 5 头发碰撞（裙摆不受影响）；241 个发刚体全部改成 `btCompoundShape`，把放大 2.0 倍的作者形状平移到该骨主导顶点的质心。新增导出 `ceris_game_hair_calibrations`，日志 `instance_created` 带 `hair_calibrations=246`；旋钮 `CERIS_HAIR_RADIUS`/`CERIS_HAIR_ALIGN`/`CERIS_HAIR_BOX`（默认 2.0/1.0/2.0）。
- 离线验收（161 帧动作 / 360 帧转身 / 360 帧站立）：平均穿透顶点 **124.27/74.29/166.91 → 2.40/3.09/0.96**，残余只在腋下/肩前；裙摆无实质回归（turn 亚毫米级变差 1→7 个顶点），帧耗时约 +1 ms。
- 也顺带证明了「垂到地面的长发穿下半身」并不存在：把身体材质扩到裙/衣/胸/袖重跑，穿透数与胸前完全一致。修复记录见 `docs/v42_头发穿模修复记录.md`。

## v41.0 运行库（2026-11-13）

- 修复**墙跑/墙跳之后裙摆与背后上身布片整片消失**（角色只剩袖片与细带、露出内裤）：角色世界旋转每帧被搬进物理世界，而裙摆 6DOF 关节平移锁死、旋转限制仅 ±0.03–0.09 rad，一帧几十度的姿态跳变会把布片甩开约 1.5 m 且永不回位。
- 修法：① `ceris_game_step` 现在也看世界旋转增量，单帧超过 25° 即重置物理（原来只看位移 > 500 cm / dt > 0.25 s）；② 新增布片漂移监控，`hq_`/`qq_`/`tc_` 布片骨相对动画姿态漂移超过 4.5 单位（≈40 cm）就按动画姿态重建布片。
- 新增导出 `ceris_game_cloth_stats`（漂移/质心/骨云半径/骨数/回弹次数/最差骨）；日志 `pose_applied` 追加 `cloth_dev`/`cloth_radius`/`cloth_rescues`，每次回弹写一行 `cloth_snap`。`cloth_diagnostics=1`。
- 离线复现（3 帧滚 85° 的墙跑姿态）：布片最大漂移 17.21 单位 / 骨云半径 8.96 / 每 200 帧回弹 182 次 → **1.60 单位 / 2.99 / 0 次**。v40 的裙摆穿透修复未回退（motion 0、turn 1、stand 0 个穿透顶点，`physics_rescues=0`）。
- 修复记录见 `docs/v41_布片被甩飞修复记录.md`。

## v40.0 运行库（2026-11-13）

- 新增**骨盆/臀部碰撞体加载期校准**，修掉裙摆被顶起、臀部穿出裙外（内裤外露）的问题。`pelvis_calibration=1`，实例创建后日志写 `pelvis_calibrations=2`。
- 根因一：saba 把 PMX 的「非衝突グループ」当成 Bullet 碰撞**白名单**直传（`(g0&m1)&&(g1&m0)`），臀部代理 `M-下半身`（group 6）与裙摆（group 6、mask 0xffbf）互不碰撞；根因二：两只臀部胶囊半径 1.05 小于臀部皮肤（1.25–1.36 PMX 单位），布料被皮肤顶穿约 1 cm。
- 修法：`下半身` / `M-下半身` 两只胶囊改为 group 0、mask 0xfffe，半径 1.25，半长与轴心不动；**PMX 资产零改动**。新增导出 `ceris_game_pelvis_calibrations`。
- 离线验收（161 帧真实动作 / 360 帧快速转身 / 360 帧静止）：最小间隙 -1.072/-2.968/-0.583 cm（25/31/21 个穿透顶点）→ **+0.359/-0.108/+0.718 cm**（0/1/0 个），`physics_rescues=0`，帧耗时不变。
- 修复记录见 `docs/v40_裙摆穿模修复记录.md`。

## v39.0 运行库（2026-11-12）

- 修复从高处落下后躯干/裙装被拉成数十米竖条：`ceris_game_step` 每帧重锚 origin 使 `root_t` 恒为 0，模型不再在局部 Bullet 世界里位移（saba 的 y=0 无限地面会托住布料/头发）。

- 修复记录见 `docs/v39_下落拉丝修复记录.md`。

- 角色与游戏原骨架存在比例差，极端动作下手臂仍可能可见拉伸。
- 仅适配 `PBZ.exe` 文件版本 `CL-302256_JKS-17280`、SHA-256 `4415933ce33476f14c837abb61a1b60af8b78cd81783896501913a7aac69e423`；游戏更新后运行库可能失效。
