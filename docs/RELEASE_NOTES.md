# 版本说明

## v37 资源包 + v38.0 运行库（2026-11-11）

首个对外归档版本。旧版 v4–v36 迭代目录已清理，不再保留。

### 资源包 v37 · `zzz_CerisMMD_v37_P`

- 完整 MMD 模型接入：943 根 PMX 原骨 + 1 根适配根（944 骨），785 刚体、1,306 个 6DOF 关节、29 项表情。
- 50,560 顶点 / 65,562 三角形 / 28 个材质区全部保留；UE 侧拆分为 51,530 可编辑顶点，GPU 16 位权重。
- 原父子层级、付与骨、IK、捩骨 swing/twist 分解保留；仅修复 Saba/Bullet 每帧重复 `setMotionState` 导致移动部件被留在原地的问题。
- 坐标按 `(PMX.x, -PMX.z, PMX.y)` 转换，沿用 110% 身高（8.8 厘米/PMX 单位）。
- 表情保留且可外部控制，未自动映射对白 / 口型 / 原角色表情事件。
- 实现细节见 `docs/v37_资源包实现记录.md`。

### 运行库 v38.0 · `CerisFullMMD`

- 新增双手武器握持修正：二段手臂 IK、锁骨辅助、捩骨调整，`grip_constraints=2`。
- 161 组编辑器动作样本：最大掌心位置误差 **0.0039 厘米（0.039 毫米）**，最大朝向误差 9.44e-7 弧度，手臂最大伸长 1.3246 倍（上限 1.35 倍）。
- UE 后处理验证：943 骨全部传输正确，最大位置误差约 1.46e-14 厘米，29 项表情曲线误差 0。
- 离线平均约 8.5 ms/帧。
- 修复记录见 `docs/v38_武器握持修复记录.md`，数据见 `validation/`。

### 已知问题

- 握持验收基于编辑器动作样本，实战画面**尚未逐帧验收**；实测 `runtime.log` 中 600 帧区间出现过 `grip_max_error_cm = 3.219832` 的极端帧，多数帧小于 0.01。
- 角色与游戏原骨架存在比例差，极端动作下手臂仍可能可见拉伸。
- 仅适配 `PBZ.exe` 文件版本 `CL-302256_JKS-17280`、SHA-256 `4415933ce33476f14c837abb61a1b60af8b78cd81783896501913a7aac69e423`；游戏更新后运行库可能失效。
- 与其他修改同一角色资源的 Mod 冲突。
- 安装凭据中 `in_game_verified` 为 `false`，即尚未完成全动作实战验收。
